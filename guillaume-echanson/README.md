# Guillaume l'Échanson — site vitrine

Maquette statique (HTML + CSS) du site de Guillaume l'Échanson, vigneron à Chassagne-Montrachet.

Voir le site en local :

    python3 -m http.server 8000

Puis ouvrir http://localhost:8000. On peut aussi ouvrir `index.html` directement dans un navigateur.

Le contexte du projet, la charte et la liste des points à valider avec Guillaume sont dans `CLAUDE.md`.

Structure :

    index.html  homme.html  biodynamie.html  reportage.html  vins.html  contact.html
    style.css
    assets/     logo, frise, photos
