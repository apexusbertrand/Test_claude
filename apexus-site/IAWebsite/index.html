Application Android

IA cave à vin

On photographie l'étiquette d'une bouteille : l'IA la lit, puis part rechercher le vin sur des sources vérifiables (domaine, cépages, fenêtre de garde, accords mets-vins, notes de critiques) pour compléter et bonifier automatiquement la fiche — sans jamais rien inventer. Reste ensuite une gestion de cave complète : stock, emplacements, statistiques, export PDF et Excel.

Techno : Flutter (Android/iOS), agent IA Claude via n8n, OCR embarqué (ML Kit), base SQLite locale
